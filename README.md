# MelodyBeats

MelodyBeats is a Java desktop application developed for my Object-Oriented Programming assignment. It manages music store items, sales, users, promotions, and receipts.

## Technologies
- Java 21
- Maven
- SQL Server
- Java Swing

## Setup
1. Run `SQL/MelodyBeat3.sql` in SQL Server.
2. Check the database settings in `DBConnection.java`.
3. Open the project in a Java IDE and run `LoginFrame.java`.
